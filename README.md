# AI Öğrenci Koçluğu Uygulaması

Bu proje, öğrenciler için yapay zeka destekli bir koçluk ve takip sistemidir.

## Özellikler

- **Akıllı Ders Programı:** Haftalık ve günlük çalışma planları oluşturur.
- **Deneme Takibi:** LGS, YKS, YDS gibi sınavlar için deneme sonuçlarını analiz eder.
- **Rehberlik Servisi:** Psikolojik testler ve rehberlik envanterleri içerir.
- **Panel Sistemi:** Öğrenci ve Koç girişleri ayrıdır.

## Kurulum ve Çalıştırma

Proje klasöründe bulunan `baslat.cmd` dosyasına çift tıklayarak uygulamayı kolayca başlatabilirsiniz.

Alternatif olarak terminal üzerinden:

```bash
npm install
npm run dev
```

## Teslimat

- **Web Sürümü:** `dist/` klasöründe production build dosyaları bulunur.
- **Android:** `android/` klasöründe mobil uygulama kaynak kodları ve build çıktıları yer alır.
- **Teslimat Notları:** Detaylı bilgi için `TESLIMAT_NOTLARI.md` dosyasını inceleyebilirsiniz.
